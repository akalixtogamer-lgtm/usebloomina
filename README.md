# Bloomina — Design System

Demonstração do design system da **Bloomina**, curadoria de semijoias (@usebloomina.semijoias).

- **Site:** `index.html`, vitrine com peças fictícias, filtro por categoria e tema Pérola/Noite
- **Apresentação:** `apresentacao/` (setas do teclado ou deslize para navegar) e `apresentacao/bloomina-apresentacao.pdf`
- **Tokens e componentes:** `assets/bloomina.css` (cores em dois temas, tipografia, vidro, botão, selo, etiqueta de preço, card de produto)

Peças, nomes e preços são fictícios. Fontes Cormorant Garamond e Jost sob licença OFL.
